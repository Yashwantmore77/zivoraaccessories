# Zivora Accessories

Website for [zivoraaccessories.in](https://zivoraaccessories.in/) — handmade accessories. *Little details. Big vibes.*

Static site: `index.html`, `styles.css`, `script.js`, images in `assets/`.
Open `index.html` in a browser to preview.

## Replacing images
- `assets/zivoraaccessories.png` — brand logo (square, ideally 600×600+)
- `assets/zivoraaccessories-1.jpg` — Navratri Special product photo (ideally 1200px+)

Keep the same file names (or update the paths in `index.html`).
